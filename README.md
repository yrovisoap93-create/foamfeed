# FoamFeed

Interactive browser simulation of a twin foam-belt pill singulator: a pill hopper feeding two cam-driven foam conveyor belts (worm drive, 20:1).

**Play with it:** open the GitHub Pages link for this repo. Works on desktop and phones. One self-contained HTML file, no install.

- Change foam material, belt speed, pill shape/size, friction
- Paint a physical belt texture (ridges / grooves) that repeats around the belts
- Upload your own container (STL/OBJ) and cam lobe (DXF, CSV, STL/OBJ)
- Desktop: drag to orbit, right-drag to pan, wheel to zoom. Phone: one finger orbits, pinch zooms/pans.

Physics values (foam, friction) are engineering estimates, not measurements.
